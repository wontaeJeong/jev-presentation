Jev의 입출력과 동작 방식

INPUT

상황 + 타입이 있는 질문

state: 긴 업무 요청

questions:
  route          Choice
  needs_web      Noul
  needs_approval Noul
OUTPUT

코드가 읽을 판단 결과

Choice선택값 + 옵션별 확률 + confidence
Noul“예”일 확률, 0~1
Score순서가 있는 등급의 확률 가중 점수

Choice·Score의 confidence는 확률 분포에서 계산합니다. 개별 답의 정답 보장은 아닙니다.

기존 기술과의 차이

기능은 겹칩니다. 무엇을 학습하고 어떤 값으로 반환하는지를 비교합니다.

기술주로 다루는 문제Jev와 비교할 지점
Classifier분류·라벨 선택질문 정의 방식과 확률 보정
Guardrail정책·위험 검사Jev가 수행할 수 있는 판단의 활용 목적
LLM-as-a-Judge응답 평가·복합 기준 판단설명·추론 필요 여부와 좁은 질문의 적합성
Structured Output출력의 스키마 준수형식 준수와 판단 정확도·불확실성은 별개

일반 LLM도 같은 답을 낼 수 있습니다. 속도·품질·출력 처리 비용은 실제로 비교합니다.
